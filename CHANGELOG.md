# Flaky Test Marker Companion Changelog

## [0.1.0]

### Added

- Gutter warning icon on any Java/Kotlin test method annotated
  `@Disabled`/`@Ignore` with no reason given, or a reason naming a
  `YYYY-MM-DD` revisit date that has already passed.
- 100% static text/PSI analysis, Java and Kotlin, no network calls, no
  telemetry. Free.
